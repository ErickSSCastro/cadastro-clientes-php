# Sistema de Cadastro de Clientes

Projeto desenvolvido como parte dos estudos em Análise e Desenvolvimento de Sistemas.

## 📌 Sobre o projeto

Aplicação web para cadastro e gerenciamento de clientes, permitindo realizar operações de inclusão, consulta, edição e exclusão de registros (CRUD).

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
- VS Code

## ⚙️ Funcionalidades

✅ Cadastro de clientes  
✅ Listagem de clientes  
✅ Edição de informações  
✅ Exclusão de registros  
✅ Integração com banco de dados MySQL

## 🗄️ Banco de dados

O projeto utiliza MySQL para armazenamento dos dados.

O arquivo SQL para criação da estrutura do banco está disponível na pasta:

`sql`

## ▶️ Como executar o projeto

1. Instalar o XAMPP
2. Copiar a pasta do projeto para:

`C:\xampp\htdocs`

3. Iniciar o Apache e MySQL no XAMPP
4. Criar o banco de dados utilizando o arquivo SQL
5. Acessar pelo navegador:

`http://localhost/clientes`

## 🎯 Objetivo

Praticar conceitos de desenvolvimento web, programação em PHP, banco de dados e operações CRUD.
